AI Exam Prep Focal Engine

Final Year Project Plan · Version 2.0 · July 2026

1. Project Vision

A zero-login, zero-cost web application where any college student uploads their course materials (PDF/PPT) and immediately gets structured AI-powered study assistance — topic explanations with visualizations, RAG-grounded Q&A, and timed MCQ mock exams — all isolated to their anonymous browser session which auto-deletes after 24 hours.

Zero-Cost Cloud Architecture Auth-Free Anonymous Sessions RAG + pgvector Mermaid + KaTeX Visualization SWR Caching

4. Design Patterns

  • Facade Pattern — lib/session.ts: single interface for all cookie/session operations
  • Repository Pattern — lib/supabase.ts: all DB access through one typed client
  • Strategy Pattern — MarkdownRenderer.tsx: auto-routes content to Mermaid / KaTeX / Prism
  • Observer Pattern — SWR hooks subscribe to query results; cache updates propagate automatically
  • Singleton Pattern — lib/gemini.ts: Xenova pipeline loads once, reused for all embed calls
  • Factory Pattern — lib/logger.ts: structured JSON log factory across all severity levels
