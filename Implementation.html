Phase 2 — Supabase Schema Setup ✅

✓ Complete — pgvector enabled, document_chunks table created and verified working.

Run in Supabase SQL Editor

-- 1. Enable extensions
CREATE EXTENSION IF NOT EXISTS vector;

-- 2. Main chunks table (session-scoped)
CREATE TABLE document_chunks (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id    text NOT NULL,
  document_name text NOT NULL,
  chunk_index   int  NOT NULL,
  content       text NOT NULL,
  embedding     vector(384),
  created_at    timestamp DEFAULT NOW()
);
CREATE INDEX idx_chunks_session ON document_chunks(session_id);

-- 3. Visitor analytics (no PII)
CREATE TABLE visitor_analytics (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id text NOT NULL,
  created_at timestamp DEFAULT NOW()
);

-- 4. Session-scoped similarity search
CREATE OR REPLACE FUNCTION match_chunks (
  query_embedding  vector(384),
  session_id_param text,
  match_threshold  float,
  match_count      int
)
RETURNS TABLE (id uuid, document_name text, content text, similarity float)
LANGUAGE sql STABLE AS $$
  SELECT id, document_name, content,
         1 - (embedding <=> query_embedding) AS similarity
  FROM   document_chunks
  WHERE  session_id = session_id_param
    AND  1 - (embedding <=> query_embedding) > match_threshold
  ORDER  BY embedding <=> query_embedding
  LIMIT  match_count;
$$;

-- 5. 24h auto-cleanup cron (enable pg_cron in Dashboard → Extensions first)
SELECT cron.schedule(
  'cleanup-old-sessions', '0 * * * *',
  $$
    DELETE FROM document_chunks   WHERE created_at < NOW() - INTERVAL '24 hours';
    DELETE FROM visitor_analytics WHERE created_at < NOW() - INTERVAL '30 days';
  $$
);

Phase 4 — Anonymous Session Layer 🔲

Step 1 — lib/session.ts (Facade Pattern)

Create lib/session.ts — wraps all cookie read/write. Every API route calls getOrCreateSessionId() instead of touching cookies directly.

Step 2 — /api/session/route.ts

POST → creates/reads session cookie, logs one row to visitor_analytics, returns { sessionId }.

Step 3 — /api/session/delete/route.ts

POST → deletes all document_chunks WHERE session_id = ?, clears cookie. Returns { deleted: N }.

Step 4 — Update Upload + Explain routes

Both routes call getOrCreateSessionId() and pass it to Supabase queries so all data is session-scoped.

Step 5 — DeleteSessionButton.tsx component

A red "Clear Session" button in the sidebar that calls /api/session/delete and resets UI state.
