2. Database Schema (Supabase)

Table: document_chunks

CREATE TABLE document_chunks (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id    text NOT NULL,          -- UUID from cookie, NOT a user account
  document_name text NOT NULL,
  chunk_index   int  NOT NULL,
  content       text NOT NULL,
  embedding     vector(384),            -- Xenova all-MiniLM-L6-v2 output
  created_at    timestamp DEFAULT NOW()
);

-- Index for fast session-scoped queries
CREATE INDEX idx_chunks_session ON document_chunks(session_id);

-- Row-Level Security: each session sees only its own chunks
ALTER TABLE document_chunks ENABLE ROW LEVEL SECURITY;
CREATE POLICY "session_isolation" ON document_chunks
  USING (session_id = current_setting('app.session_id', true));

Table: visitor_analytics

CREATE TABLE visitor_analytics (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id text NOT NULL,    -- anonymous UUID only, no PII
  created_at timestamp DEFAULT NOW()
);

Function: match_chunks (updated for session isolation)

CREATE OR REPLACE FUNCTION match_chunks (
  query_embedding  vector(384),
  session_id_param text,
  match_threshold  float,
  match_count      int
)
RETURNS TABLE (id uuid, document_name text, content text, similarity float)
LANGUAGE sql STABLE AS $$
  SELECT id, document_name, content,
         1 - (embedding <=> query_embedding) AS similarity
  FROM   document_chunks
  WHERE  session_id = session_id_param
    AND  1 - (embedding <=> query_embedding) > match_threshold
  ORDER  BY embedding <=> query_embedding
  LIMIT  match_count;
$$;

Cron Job: 24h Auto Cleanup

-- Enable pg_cron extension in Supabase Dashboard → Extensions
SELECT cron.schedule(
  'cleanup-old-sessions',
  '0 * * * *',   -- runs every hour
  $$
    DELETE FROM document_chunks
    WHERE created_at < NOW() - INTERVAL '24 hours';

    DELETE FROM visitor_analytics
    WHERE created_at < NOW() - INTERVAL '30 days';
  $$
);

3. Session Facade — lib/session.ts

Single entry point for all session operations. Routes never touch cookies directly (Facade Pattern).

// lib/session.ts
import { cookies } from 'next/headers'
import { randomUUID } from 'crypto'

const SESSION_COOKIE = 'exam-session-id'
const TTL_SECONDS = 60 * 60 * 24 // 24 hours

export function getSessionId(): string | null {
  return cookies().get(SESSION_COOKIE)?.value ?? null
}

export function getOrCreateSessionId(): string {
  const existing = getSessionId()
  if (existing) return existing
  const id = randomUUID()
  cookies().set(SESSION_COOKIE, id, {
    httpOnly: true,
    sameSite: 'lax',
    maxAge: TTL_SECONDS,
  })
  return id
}

export function clearSessionCookie(): void {
  cookies().delete(SESSION_COOKIE)
}

5. Visualization Renderer — Strategy Pattern

MarkdownRenderer.tsx uses a Strategy pattern to delegate rendering based on content type detected in AI markdown streams.

// components/MarkdownRenderer.tsx
export default function MarkdownRenderer({ content }: { content: string }) {
  // 1. Parse markdown for special block patterns
  const blocks = parseBlocks(content)

  return blocks.map(block => {
    // 2. Route to specialized Renderer component (Strategy)
    if (block.type === 'mermaid') return <MermaidRenderer code={block.code} />
    if (block.type === 'math')    return <KaTeXRenderer math={block.code} />
    if (block.type === 'chart')   return <ChartRenderer data={block.json} />
    return <div>{block.text}</div>
  })
}

ChartRenderer.tsx takes JSON data in a ```chart block and generates a dynamic, thin-wrapper SVG without heavy chart library dependencies.

7. Error Handling Contract

LayerHow Error is Handled
API RoutesAll wrapped in try/catch. Always return { error: string } with correct HTTP status. Never return raw exceptions.
LlamaParse timeoutPoll max 24×5s = 120s. If no result: 500 with clear message. Frontend shows retry button.
Groq API failureCatch, log via logger.error(), return 500. Frontend shows friendly error card.
Session missingAPI reads session cookie; if absent, returns 400 "Session not found".
FrontendSWR error state triggers a red error card with the error message.
